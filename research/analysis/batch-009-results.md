## Interpretation

**Result C refined: the ρ vector under A_{sparseFN} is binary.** The α ceiling is not about estimator choice — it's a property of the adversarial model.

The debug analysis reveals:

| Case | Boundary nodes | Critical (ρ=0.8) | Clean (ρ=1.0) |
|------|---------------|-------------------|----------------|
| WRK-002 | {t2} | t2 (Pm true→false) | — |
| WRK-003 | {t2, t2_next} | t2 (Pm true→false) | t2_next (Pm true, rarely hit) |
| DEP-005 | {t, v3} | v3 (Pr true→false) | t (all false, corruption-immune) |

Critical nodes have exactly **one** true dimension (matching the sensitivity). The fn corruption flips that dimension to false, making 4/5 dims match → ρ = 0.80. This value is **invariant**: regardless of incidence, the critical node always gets corrupted (unconditional flip in `applySparseFn`), so ρ_critical = 0.80 in every single run.

Clean boundary nodes either have all-false capabilities (t in DEP-005, v3_next) or the same single-true-dimension pattern (t2_next in WRK-003). All-false nodes are **corruption-immune**: flipping any dim false→false produces ρ = 1.00 always. Single-true nodes are only corrupted if random incidence + random dim both match, which occurs at ~2% per run.

### What this means

The ρ vector under A_{sparseFN} is:

```
ρ ∈ {0.80, 1.00}
```

with a fixed structure (1 critical + 0-N clean) that is **invariant to incidence**. No function of ρ — min, max, variance, skewness, kurtosis, entropy — can produce α > 0.2. The information was never there.

**Batch-009.1 (signal mining) confirms:** There is no latent signal in the ρ vector. Every scalar function of ρ was already fully captured by α = 1 − median(ρ) = 0.10–0.20.

Implication: The theory must shift from "find a better function of ρ" to "find a different signal entirely." The ρ vector at k=1 is too impoverished to detect fn corruption at the resolution required for ProbeReliability@τ ≥ 0.3.
