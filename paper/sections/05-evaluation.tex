\section{Empirical Validation \& Component Ablation (EXP-004)}

The formal model identifies the conditions under which capability removal violates
decision preservation. EXP-004~\cite{takt_st016_2026} tests whether these conditions
are observable in the reference TypeScript implementation under controlled ablations:

\begin{itemize}
    \item \textbf{$C_{\text{contract}}$ Ablation:} Ablating contract verification
    yields $\pi_{\text{full}} = \text{STOP}$ vs.\ $\pi_{\text{reduced}} = \text{EXECUTE}$.

    \item \textbf{$C_{\text{uncertainty}}$ Ablation:} Ablating margin estimation
    at critical decision boundary ($M_D \approx 0$) yields
    $\pi_{\text{full}} = \text{REFINE}$ vs.\ $\pi_{\text{reduced}} = \text{EXECUTE}$.

    \item \textbf{$C_{\text{temporal}}$ Ablation:} Ablating trajectory monitoring
    yields $\pi_{\text{full}} = \text{INTERVENE}$ vs.\ $\pi_{\text{reduced}} = \text{MONITOR}$.
\end{itemize}

Each ablation scenario is manually encoded into a \texttt{WitnessArtifact} record
and verified against the formal model via the \texttt{WitnessConsistentWithRuntime}
predicate. When consistency holds, the formal elevation theorem applies.
