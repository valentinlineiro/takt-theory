\section{Machine-Certified Lean 4 Formalization}

The Lean 4 development in \texttt{takt-formal} provides the algebraic framework
within which the ST-016 runtime model is defined and analyzed. Two canonical
modules are presented.

\subsection{Core Definitions in \texttt{RuntimeSufficiency.lean}}

The module defines the core algebraic structures. The key definitions, shown
verbatim from the Lean source, are:

\begin{small}
\begin{verbatim}
inductive RuntimeCapability
  | contract | uncertainty | temporal

structure Runtime (S : Type) (D : Type) where
  capabilities : Set RuntimeCapability
  policy       : S -> D

def NecessaryCapability (C : RuntimeCapability) (M : Runtime S D) : Prop :=
  Exists r, M.policy r != (removeCapability M C).policy r

def Sufficient (M : Runtime S D) (pi_star : S -> D) : Prop :=
  forall r, M.policy r = pi_star r

def Irreducible (M : Runtime S D) : Prop :=
  forall C, C in M.capabilities -> NecessaryCapability C M

def MinimalRuntime (M : Runtime S D) (pi_star : S -> D) : Prop :=
  Sufficient M pi_star /\ Irreducible M
\end{verbatim}
\end{small}

As a definitional consequence of these definitions, any \texttt{MinimalRuntime}
has all its capabilities necessary by construction (since \texttt{Irreducible}
is the second conjunct of \texttt{MinimalRuntime}). The module also proves the
non-trivial lemma \texttt{necessary\_implies\_non\_preservation}: that a necessary
capability, when removed, strictly breaks \texttt{PreservesDecision}.

\subsection{Formal Witness Validation Schema (\texttt{RuntimeWitness.lean})}

Defines the formal witness validation schema via \texttt{WitnessArtifact} and
\texttt{WitnessConsistentWithRuntime}. A \texttt{WitnessArtifact} is a record
\emph{manually constructed} from an observed ablation scenario (e.g., EXP-004
traces). The elevation theorem:
\[
\text{Consistent}(M, w) \implies \text{NecessaryCapability}(w.\mathit{cap}, M)
\]
guarantees that \emph{if} a witness is consistent with the formal runtime model,
\emph{then} the corresponding capability is formally necessary within that model.

Both modules compile with zero errors and zero \texttt{sorry}s~\cite{takt_st016_2026}.
