\section{Machine-Certified Lean 4 Formalization}

The Lean 4 development in \texttt{takt-formal} provides the algebraic framework
within which the ST-016 runtime model is defined and analyzed. Two canonical
modules are presented:

\begin{enumerate}
    \item \textbf{\texttt{RuntimeSufficiency.lean}:} Defines the core algebraic
    structures (\texttt{RuntimeCapability}, \texttt{Runtime}, \texttt{NecessaryCapability},
    \texttt{MinimalRuntime}) and establishes that the definitions are internally consistent.
    The module proves, as a definitional consequence, that any runtime satisfying
    \texttt{MinimalRuntime} (i.e., \texttt{Sufficient} $\wedge$ \texttt{Irreducible})
    has all its capabilities necessary by construction:
    \[
    \text{MinimalRuntime}(M, \pi^*) \implies
    \forall C \in M.\mathit{caps},\; \text{NecessaryCapability}(C, M)
    \]
    This is a consequence of the definition of \texttt{Irreducible}, establishing
    the definitional coherence of the framework rather than a new mathematical fact.

    \item \textbf{\texttt{RuntimeWitness.lean}:} Defines the \emph{formal witness
    validation schema} via \texttt{WitnessArtifact} and \texttt{WitnessConsistentWithRuntime}.
    A \texttt{WitnessArtifact} is a record manually constructed from an observed
    ablation scenario (e.g., EXP-004 traces). The elevation theorem:
    \[
    \text{Consistent}(M, w) \implies \text{NecessaryCapability}(w.\mathit{cap}, M)
    \]
    guarantees that \emph{if} a witness is consistent with the formal runtime model,
    \emph{then} the corresponding capability is formally necessary within that model.
    The bridge is a validation schema, not an automatic extraction from TypeScript traces.
\end{enumerate}

Both Lean 4 modules compile cleanly with zero errors and zero \texttt{sorry}s
across all build jobs~\cite{takt_st016_2026}. The structural sufficiency results
(kernel factorization, quotient representation theorems) are in
\texttt{StructuralSufficiency.lean} and \texttt{Kernel.lean}, which provide
the informational foundation connecting ST-015 and ST-016.
