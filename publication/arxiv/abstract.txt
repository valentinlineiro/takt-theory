TAKT: A Formal Framework for Minimal Decision-Preserving Runtime Governance

Software systems operating under abstracted or compressed state representations
frequently risk decision instability when critical informational context is
discarded. This paper introduces TAKT (Theory of Adequate Knowledge for
Decisions), a formal and empirical framework for characterizing minimal
governance kernels of execution runtimes. Within the formal ST-016 runtime
model, we develop a Lean 4 algebraic framework defining runtime capability
necessity, decision preservation, sufficiency, and irreducibility, and
demonstrate -- on finite witness instances within the model -- that three
capability classes -- ContractSoundness (C_contract), UncertaintyBound
(C_uncertainty), and TemporalConsistency (C_temporal) -- each have formalized
witness scenarios where their removal violates decision preservation.

We validate these witnesses on a reference TypeScript runtime via component
ablation (EXP-004), connected to the formal model via a formal witness
validation schema. We present an audited zero-contact replication package
across six independent audit rounds, backed by an immutable Zenodo archive
(DOI: 10.5281/zenodo.21638014).
