treats **time** as a primary dimension. All previous layers are static in the
following sense:

## 1. The Core Question

> Given a transition system `T`, a strategy `S`, and an evaluation criterion `E`,
> under what conditions does the sequence of trajectories generated by repeated
> execution of `S` on `T` converge toward a stable region?

This question has three subquestions that must be answered in order:

1. **What is a stable region?** (Fixed points, attractors, oscillation cycles)
2. **What does "converge toward" mean?** (Convergence criterion, rate)
3. **Under what conditions does convergence hold?** (Sufficient conditions)

---

## 2. Trajectory Sequences

### 2.1 Single Trajectory vs. Trajectory Sequence

Strategy Theory and Optimization Theory operate on a single `RunResult`. Convergence
Theory introduces **trajectory sequences** — the output of running a strategy
repeatedly, where each run may start from a state updated by the previous run.

```
Run₀: initialState → trajectory₀ → terminalState₀
Run₁: f(terminalState₀) → trajectory₁ → terminalState₁
Run₂: f(terminalState₁) → trajectory₂ → terminalState₂
...
```

The function `f` is the **restart policy** — how a new run is initialized from
the terminal state of the previous run. This is a design choice external to the
strategy itself, keeping strategies pure.

### 2.2 Trajectory Sequence Type

```typescript
interface TrajectorySequence<S, A> {
  readonly trajectories: ReadonlyArray<TrajectoryPrefix<S, A>>;
}
```

A `TrajectorySequence` is the primary observable of Convergence Theory.

### 2.3 State Sequence

From a trajectory sequence, we extract the **state sequence** — the sequence of
terminal states across runs:

```
stateSequence(seq) = [terminalState(τ₀), terminalState(τ₁), terminalState(τ₂), ...]
```

where `terminalState(τ) = τ.states[τ.states.length - 1]`.

This reduction is important: convergence can be studied at the level of states
rather than full trajectories, which simplifies the theory.

## 3. Stability Concepts

### 3.1 Fixed Point

A state `s*` is a **fixed point** of strategy `S` on transition system `T` if,
when `S` is run from `s*`, the resulting trajectory terminates at `s*`:

```
fixedPoint(s*, S, T) iff terminalState(run(S, s*)) = s*
```

Fixed points are the degenerate case of convergence: the system reaches a state
it cannot leave under strategy `S`.

### 3.2 Stable Region

A set of states `R ⊆ StateSpace` is **stable** under strategy `S` if, once
entered, the state sequence never leaves `R`:

```
stable(R, S, T) iff ∀s ∈ R: terminalState(run(S, s)) ∈ R
```

Fixed points are singleton stable regions: `stable({s*}, S, T)`.

### 3.3 Attractor

A stable region `A` is an **attractor** if there exists a basin of attraction `B ⊇ A`
such that all state sequences starting in `B` eventually enter `A` and remain there:

```
attractor(A, B, S, T) iff
    stable(A, S, T) ∧
    ∀s ∈ B: ∃n: ∀k ≥ n: stateAt(k, s) ∈ A
```

where `stateAt(k, s)` is the terminal state after `k` runs of `S` starting from `s`.

### 3.4 Oscillation

A state sequence **oscillates** with period `p` if:

```
oscillates(seq, p) iff ∀n ≥ n₀: stateAt(n+p) = stateAt(n)
```

Oscillation is the failure mode of convergence: the system cycles without settling.
Period-1 oscillation is a fixed point.

### 3.5 Divergence

A state sequence **diverges** if it visits infinitely many distinct states and
never enters a stable region. In finite state spaces, divergence implies
oscillation with unbounded apparent period (i.e., the cycle length exceeds the
observation window).

## 4. Convergence Criterion

### 4.1 Definition

A strategy `S` **converges** on transition system `T` from initial state `s₀`
under evaluation space `E` if:

```
converges(S, T, s₀, E) iff
    ∃ stable region R:
        stateSequence(S, T, s₀) eventually enters R ∧
        the E-performance of trajectories in R is non-increasing
```

The second condition ties convergence to the evaluation order: the strategy must
not only stabilize spatially but also stabilize in terms of performance.

### 4.2 Convergence Rate

The **convergence rate** is the number of runs required before the state sequence
enters and stays within an ε-neighbourhood of the attractor under evaluation space `E`.

For finite discrete systems (TAKT's primary domain), ε-neighbourhoods reduce to
exact membership in a stable region. The convergence rate is then:

```
rate(S, T, s₀) = min { n : ∀k ≥ n: stateAt(k, s₀) ∈ A }
```

This is an observable quantity, computable empirically.

## 5. Sufficient Conditions for Convergence

### 5.1 Finite State Space + Monotone Strategy

**Theorem (informal):** If the state space is finite and strategy `S` is
monotone under evaluation space `E` (each run produces an outcome no worse than
the previous), then the state sequence converges in at most `|StateSpace|` steps.

**Proof sketch:** A monotone sequence over a finite preorder must eventually
stabilize (no infinite strictly descending chain exists in a finite set).

### 5.2 Admissible Strategy + Complete Exploration

**Theorem (informal):** If `isAdmissible(S, P)` holds and the transition system
has finite branching and a finite diameter, then the state sequence converges to
an optimal stable region in finite time.

This bridges Optimization Theory (admissibility) and Convergence Theory (stability).

### 5.3 Composition and Convergence

- **fallback(A, B)**: Convergence is inherited from whichever component is
  active at the stable region. If `A` converges and `A` is never DEFERring at
  the attractor, then `fallback(A, B)` converges to the same attractor.
- **depthBound(S, b)**: A depth-bounded strategy always terminates in finite
  steps per run, bounding the per-run cost. Convergence to an attractor is
  possible only if the attractor is reachable within depth `b`.

## 6. Landscape Connection

Convergence Theory closes the loop back to Landscape Theory:

```
Landscape
    ↓
gradient structure (Φ)
    ↓
determines which attractors exist
    ↓
Strategy + Convergence
    ↓
determines which attractors are reachable
```

A **landscape-compatible strategy** is one whose attractors coincide with the
landscape's local optima under `Φ`. This is the TAKT formalization of gradient
descent compatibility.

The existence of gradient-compatible strategies is a theorem about the joint
structure of `(Landscape, Strategy)`, not about either in isolation.

## 7. Observable Interface (Implementation Target)

The following observables are needed to make Convergence Theory computable:

```typescript
// A sequence of RunResults from repeated execution
interface ConvergenceTrace<S, A> {
  readonly runs: ReadonlyArray<RunResult<S, A>>;
  readonly stateSequence: ReadonlyArray<S>;
}

// Predicate: has the trace entered a stable region?
function hasStabilized<S, A>(
  trace: ConvergenceTrace<S, A>,
  windowSize: number,
  stateEq: (a: S, b: S) => boolean
): boolean;

// Predicate: is the trace oscillating with period p?
function isOscillating<S, A>(
  trace: ConvergenceTrace<S, A>,
  period: number,
  stateEq: (a: S, b: S) => boolean
): boolean;

// Empirical convergence rate: first run index after which trace is stable
function convergenceRate<S, A>(
  trace: ConvergenceTrace<S, A>,
  windowSize: number,
  stateEq: (a: S, b: S) => boolean
): number | null;

// Runner for repeated execution with restart policy
function runSequence<S, A>(
  strategy: Strategy<S, A, DeterministicDecision<S, A>>,
  problem: SearchProblem<S, A>,
  restartPolicy: (terminalState: S) => S,
  runs: number
): ConvergenceTrace<S, A>;
```

## 8. Open Questions for Subsequent Phases

1. **Stochastic convergence**: under randomized strategies, convergence holds
   in expectation or with probability 1 — this requires probability theory.
2. **Landscape evolution**: if the landscape itself changes between runs
   (adaptive landscapes), stable regions may shift. This is Adaptive Search.
3. **Multi-agent convergence**: when multiple strategies operate on the same
   transition system simultaneously. Out of scope for Convergence Theory Phase 1.
4. **Convergence speed vs. solution quality trade-off**: a fast-converging
   strategy may converge to a poor attractor. Formalizing this trade-off
   is the bridge to Volume III.

## 10. Architectural Invariants

1. **Strategies remain pure.** The restart policy is external; strategies do not
   observe across runs.
2. **`ConvergenceTrace` is the sole observation surface.** No predicate reaches
   into the runner loop.
3. **Convergence is always relative.** `converges(S, T, s₀, E)` — never absolute.
4. **Oscillation is not a defect.** It is a valid and correctly-named outcome
   that the theory must represent without prejudice.
5. **Finite state spaces first.** Continuous or infinite state space convergence
   is deferred to subsequent phases.
