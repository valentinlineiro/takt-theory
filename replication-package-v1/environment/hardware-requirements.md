# Hardware Requirements for R1 Independent Replication

- **CPU:** x64 or ARM64 multi-core processor (minimum 2 cores)
- **RAM:** Minimum 4 GB available system memory
- **Storage:** Minimum 500 MB free disk space
- **OS:** Linux (Ubuntu 20.04+, Debian 11+), macOS 12+, or Windows 10/11 WSL2
- **Runtime:** Node.js `>= v20.0.0`
